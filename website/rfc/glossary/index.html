供用户、个人 Agent 与客户端交换持久消息和记忆资料的通用服务。服务记录投递、收取和版本事实，参与方可以在不同时间上线。

Language

Space / 用户空间：一个所有者管理的身份、信箱和记忆授权边界。不同空间的对象不可因名称相同而互相访问。

Actor / 参与者：空间内可识别的用户、Agent 或客户端身份。显示名称可以修改，身份本身保持稳定。 Avoid：把产品品牌、令牌或设备直接当作参与者。

Principal / 调用主体：经过认证并具有明确参与者身份与授权范围的请求发起方。

Consumer / 消费者：一个稳定的收取身份，绑定参与者与可读视图。不同消费者独立保存收取和处理记录。 Avoid：把消费者等同于收件人或临时网络连接。

Mailbox / 信箱：参与者获准收取的消息与资料变化集合。内容可以在接收方离线时提交。

Message / 消息：一次已发布的不可变信息投递，包含收件范围、正文、来源和附件引用。 Avoid：把消息当作已经完成的任务。

Thread / 会话：关联同一主题往返消息的稳定记录。会话参与者受独立的访问授权约束。

Submission / 提交：参与者发起的一次具有稳定请求标识的写入尝试。它可以尚未发布，也可以已经发布但回执尚未送到。

Commit / 发布：内容就绪并已进入可读取记录的状态变化。保存成功回执对应这一边界。 Avoid：把上传暂存或开始执行请求称为发布成功。

Receipt / 回执：消费者声明已经可靠收取或处理某项输入的记录。它不自动证明任何外部动作成功。

Feed / 增量记录：按发布顺序提供、可以从位置继续读取的可见变化集合。

Cursor / 游标：消费者在特定可读视图中的读取位置。它不表示该位置之前的业务工作均已完成。

Blob / 资料对象：服务管理的文件内容，由稳定引用定位。暂存上传和可被引用的最终资料是不同状态。

Collection / 记忆集：具有固定来源与授权范围的记忆条目集合。来源资料与其他参与者整理后的资料可以分别成为记忆集。

Memory Item / 记忆条目：记忆集内具有稳定标识的资料及其来源说明。条目不因正文变化而自动获得新身份。

Revision / 记忆版本：一次已发布的记忆集状态。它明确覆盖哪些条目和删除标记。

Snapshot / 完整快照：对一个明确记忆集完整内容的替换声明。局部资料应表达为增量。

Delta / 增量：基于指定版本的新增、修改与明确删除集合。遗漏未列出的条目不表达删除。

Tombstone / 删除标记：记忆条目在某一版本被明确删除的记录。它不删除其他来源的同名条目。

Event / 事件：一项已经发布的事实变化通知，具有稳定身份。通知被收到与关联内容被处理是不同事实。

Subscription / 订阅：某个主体在授权范围内接收指定变化的安排，包括过滤条件、交付方式与有效期。

Adapter / 适配器：把相同领域操作映射到特定传输、存储或平台的边界。平台的回调格式不改变消息与记忆的领域含义。
