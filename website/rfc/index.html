How the spec evolves

Drafts are the implementation baseline, not a promise that every ability is live. When observable behavior or permission meanings change, version and migration notes ship with it; implementation state is confirmed through property tests and real acceptance.

The site is generated from repo docs, keeping source content and status. Diagrams keep their Mermaid source and the raw Markdown downloads; where implementation differs, validation and security notes rule.
