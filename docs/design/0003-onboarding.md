# 主助手接入与托管邀请

用户已确认：先修托管权限配置，再验证接入助手经 Waypost 向主助手交接，并完善邀请入口。Muse 暂不可用，由当前助手扮演主助手，标准 MCP 客户端模拟接入助手；不将该验收描述为已验证 Muse 产品集成。

## 用户用语

- 主助手：用户主要对话的助手，收取接入助手的结果，整理进展并向用户汇报。身份角色不自动授予权限。
- 接入助手：通过独立连接交付结果的助手。首次接入只有发信能力。
- 邀请：服务运行者为一个用户空间签发的有期限、可撤销、一次性接入凭据。领取后获得该空间的个人登录凭据。

## 本次范围

1. Dashboard 所有管理列表遵守当前部署的分页上限，并保持分页完整。
2. 空间可指定一位主助手；修改带版本检查，角色与连接能力分开管理。
3. 连接可设置明确的默认收件人。旧连接仍默认向用户入口发信；发送方的默认收件人必须在获准范围内。
4. 提供邀请签发与领取，领取只进入对应个人空间；邀请失效、撤销、重复领取、空间越界均拒绝。
5. 提供主助手与接入助手的接入模板、标准 MCP 交接验收和上线记录。
