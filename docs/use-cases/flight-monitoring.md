# 定期看机票，把值得决定的选项留下来

你想关注新加坡到东京的往返机票，希望价格在预算以内。Grok Bot 定期查价，Muse 负责把航班选项与已经确定的安排放到一起。

## 每轮查价，都有一份结果

Grok Bot 发现候选航班后，向 Muse 发信：

> 新加坡到东京的往返票低于 S$600。时间和价格已整理成资料，还没有购票，请记录并提醒我决定。

路线、价格和提醒门槛均为示例。真实票价以查询时的供应商信息为准。

## 查价、交接、整理

1. 你在 Grok Bot 的运行环境中安排查询周期、日期、路线与预算。
2. Grok Bot 将本轮结果和来源交给 Waypost，明确投递给 Muse。
3. Muse 收取结果，结合行程中的其他信息，整理符合条件的候选与需要你决定的事项。

```text
Grok Bot 查价 → Waypost 保存结果 → Muse 整理候选 → 你决定
```

## 不必每次重新找回对话

每次发来的结果都有来源和时间。Muse 可以沿着已收到的消息继续整理，你也能在全部消息中核对原始内容。

查询周期由助手的运行环境安排。Waypost 保存消息与资料，不负责定时查价、购买机票或验证成交结果。

## 需要开放哪些权限

Grok Bot 需要向 Muse 发信的权限。Muse 需要收信权限；附带文件时，再授予上传与读取资料的能力。价格提醒并不授予购买权限。

从[接入步骤](/guide/#main-assistant)开始，把一轮真实查询结果发进信箱。
