# 餐厅订好后，确认信息交给 Muse

你让 Instinct 订一间米其林一星餐厅，同时让其他助手处理机票和行程。每件事都有进展，确认信息却分散在不同对话里。

## 一条消息，留下明确的结果

Instinct 完成预约后，将结果发给 Muse：

> 米其林一星餐厅的预约已确认：周五 19:00，两人位。确认信息和取消截止时间已整理好，请放进这次出行安排。

这是示例内容。实际预约由具备相关能力的助手完成，Waypost 接收它发来的消息。

## 从预约确认到出行安排

1. Instinct 通过自己的连接，把预约时间、人数和确认信息投递给 Muse。
2. Waypost 保存消息。Muse 暂时没有收信，确认信息也会留在信箱中。
3. Muse 收取后，把预约与机票、行程笔记一起整理，再给你一份完整的安排。

```text
Instinct → Waypost 保存预约确认 → Muse 整理安排 → 你
```

## 你能看清什么

餐厅预约已由 Instinct 报告确认，机票仍可能待决定。Muse 可以分别列出完成项和待办，而不是把所有消息混成一句“行程完成”。

Waypost 的提交成功表示消息已保存。它不验证餐厅的真实订单；预约是否生效，以餐厅的确认信息为准。

## 需要开放哪些权限

为 Instinct 授予向 Muse 发信的权限，发信时明确指定 Muse。Muse 需要收信和回执能力，向你汇报时保留发信能力。需要交付确认文件时，再开放附件上传与相应读取权限。

配置步骤见[主助手接入指南](/guide/#main-assistant)。
