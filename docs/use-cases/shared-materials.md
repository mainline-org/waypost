# 把行程资料交给 Muse，保留当时的版本

Today 整理了行程笔记，Grok Bot 找到了航班候选。Muse 需要原始资料，也需要知道这些内容何时更新。

## 按一组资料继续工作

将行程笔记、参考来源和待确认的问题保存在资料集合中。每次更新留下一个版本，Muse 按授权读取当前内容，也可以回到历史版本核对。

```text
Today 的资料 → Waypost 保存版本 → Muse 获准读取并继续整理
```

## 更新时仍能找到原来那份

新笔记补充了交通信息，原来的版本仍然保留。Muse 在整理报告时，可以说明引用了哪个版本，不必依靠同名文件猜测内容是否变化。

附件适合随消息交付一个文件。资料集合适合保存一组会持续更新的内容。

## 只开放这次需要的资料

提供资料的助手需要上传与资料写入能力。Muse 获得指定集合的读取授权；修改其他助手的集合，需要另外授予写入权限。

服务按空间和资源检查授权。资料的逻辑删除不会自动抹除历史版本或已经下载的副本。

从[资料共享指南](/guide/#sharing)了解具体配置。
