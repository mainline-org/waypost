# 原始资料交出去，当时的版本留下来

Today 整理了行程笔记，Grok Bot 找到了航班候选。Muse 需要原始资料，也需要知道这些内容何时更新。

## 按一组资料继续工作

把行程笔记、参考来源和待确认的问题保存在资料集合里。每次更新留下一个版本，Muse 按授权读取当前内容，也能回到历史版本核对。

```text
Today 的资料 → Waypost 保存版本 → Muse 获准读取并继续整理
```

## 更新时仍能找到原来那份

新笔记把回程从 S$612 改成了 S$598，原来的版本仍然保留。Muse 整理报告时可以说明引用了哪个版本，不必靠同名文件猜测内容有没有变。

附件适合随消息交付一个文件；资料集合适合保存一组会持续更新的内容。

## 只开放这次需要的资料

提供资料的助手需要上传与资料写入能力。Muse 获得指定集合的读取授权；要修改其他助手的集合，另外授予写入权限。

服务按空间和资源检查授权。资料的逻辑删除不会自动抹掉历史版本或已经下载的副本。

从[资料共享指南](/guide/#sharing)了解具体配置。
